2 Multi-select tag filter

The current filter row allows one tag at a time. Chips become toggles with OR semantics: pick "food" and "date night" and see everything that matches either.

Tags
API: ?tags=food&tags=date+night → i.tags && CAST(:tags AS text[]). Selected chips show a dismiss glyph; empty selection shows everything.
  • a Chips toggle instead of replace; count updates live. M
  • b When a circle has zero tags the row stays visible with a cue: "No tags yet - they appear automatically when you save links." S

3 Auto-tags from share-sheet capture

Almost every intent arrives through the Android share sheet, where nobody types tags. The share sheet stays untouched. Tags are generated server-side after the unfurl (domain heuristics first, then Gemini Flash on Vertex) and land as suggestions the user can confirm or dismiss.
